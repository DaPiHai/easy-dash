# easy-dash v0.3.0

多显示器适配版本：每块屏独立顶栏、按屏全屏隐藏、控制中心可配置副屏 Dock，并把窗口定位/托盘锚点统一到屏幕物理坐标。

## 新增

- **每屏顶栏**：`topbar-<device>` 动态窗口，每块显示器各有一条 32px 顶栏，独立展开通知中心/控制中心，独立响应全屏自动隐藏；顶栏默认在每块屏显示。
- **副屏 Dock（可选）**：默认只在主屏；控制中心「多屏」卡片可开启「副屏 Dock」，副屏底部居中显示一套 Dock。
- **按屏 AppBar**：每块顶栏注册为该显示器的 AppBar，最大化窗口自动避开顶栏；`reserveTopbarSpace` 关闭时全部屏都不预留。
- **显示器热插拔**：监控线程每约 2 秒比对显示器签名（位置/分辨率/缩放/主屏），自动创建、移动或销毁窗口与 AppBar。
- **按屏全屏隐藏**：只隐藏全屏应用所在屏的顶栏/Dock；新窗口启动时主动读取一次状态。
- **概览/应用中心跟随触发屏**：点哪块屏的「活动」/Dock 九点格就在哪块屏打开；热键按鼠标所在屏；管理面板在触发屏居中。
- **副屏工作区释放**：隐藏系统任务栏时临时开启任务栏 `ABS_AUTOHIDE`，让 Explorer 重算所有显示器工作区，副屏最大化窗口不再在底部留下任务栏条带；不修改任务栏 AppBar 注册，原 auto-hide 状态写入强杀标记并在退出/下次启动恢复。
- **托盘坐标修正**：顶栏图标锚点由 `ClientToScreen` + 该窗口 DPI 换算，副屏右键菜单夹在副屏顶栏下方，日志增加 `monitor=` 字段。

## 变更

- 控制中心新增「多屏」卡片，面板高度 476 → 560（窗口 644）。
- 管理面板新增「多屏」页：显示器列表（名称/分辨率/缩放/坐标/主屏徽标）+ 副屏顶栏 / 副屏 Dock 开关 + 工作区与触发屏说明；单屏时开关置灰。
- **修复运行中开启副屏 Dock 卡死**：每块屏的顶栏/Dock 启动时预创建为隐藏窗口，配置切换只 show/hide；显示器重建改到后台线程，避免动态建 WebView 重入卡死。
- **修复副屏顶栏重新开启后压在全屏窗口顶部**：AppBar 注册不再要求窗口先可见；顶栏/Dock 重新显示时补查全屏状态；全屏检测改为以完整覆盖显示器为准（兼容 Chrome/Edge 带 `WS_CAPTION` 的 F11 全屏）。
- **修复退出后任务栏偶发不恢复**：恢复开始时先清除隐藏意图并让 watchdog 让路，避免恢复过程中被重新藏回。
- 窗口 label 改为 `topbar-*` / `dock-*`（capabilities 使用 glob）；`fullscreen-changed` 改为按窗口定向推送，`close-panels` 广播到所有顶栏。
- 托盘 UIA 回退模式只在主屏顶栏显示托盘；代理模式每屏都显示。

## 已知限制

- **副屏工作区**：通过临时开启系统任务栏 auto-hide 释放，依赖 Explorer 的 AppBar 重算；若系统/第三方任务栏替换工具阻止 `ABM_SETSTATE`，副屏底部条带仍可能出现（会记录日志）。关闭「隐藏任务栏」后条带随任务栏恢复。
- 通知中心系统入口仍由 Windows 决定弹出屏幕（通常主屏）；亮度滑条仍控制第一台支持 DDC/CI 的显示器。
- 概览/应用中心不跨屏铺满，只在触发屏打开。

## 升级说明

- 配置文件新增 `topbarAllMonitors`（默认 `true`）、`dockAllMonitors`（默认 `false`），旧配置自动补齐。
- 控制中心新增「多屏」卡片；单显示器时开关置灰。
