# easy-dash v0.2.0

主题系统、系统任务栏隐藏与视觉重构版本：控制中心/通知中心改为 Apple 控制中心 × Raycast 的「Aurora Glass」风格，
应用中心改为分页网格，并适配亮色 / 暗色 / 跟随系统主题。

## 亮点

- **系统任务栏自动隐藏**：启动时隐藏 Windows 原生任务栏（主屏 + 副屏），退出时自动恢复；管理面板可随时开关。
  隐藏期间通过「透明桥接」短暂以 `alpha=0` 显示任务栏来完成托盘 UIA 枚举与点击，顶栏托盘镜像保持可用。
  Explorer 重启后自动重新隐藏；异常退出后重启 easy-dash 会先恢复。
- **亮色 / 暗色 / 跟随系统主题**：控制中心「外观」三段切换，五个窗口即时同步；跟随系统每 2s 读取 Windows 主题；
  配置持久化、首帧无闪烁。管理面板可设置「同时控制系统主题」。
- **应用中心分页**：应用网格按可视区自动分页，支持鼠标滚轮 / 触控板 / `PageUp`·`PageDown` / `Home`·`End` / 方向键换页，
  新增圆点·箭头·页码分页器；搜索同样分页；拖拽排序保留页内实时让位、拖到边缘自动翻页，跨页顺序持久化。
- **控制中心 / 通知中心重构**：Aurora Glass 视觉（Apple 控制中心分组磁贴 + Raycast 表面阶梯/发丝边），
  统一 Lucide 图标集；控制中心重排快捷开关 / 外观 / 音量亮度 / 连接 / 电源；通知中心重做通知卡、节假日月历与媒体卡；
  亮暗双主题完整适配。
- **设计规范**：新增 `docs/design-system.md`（tokens、组件规格、图标许可、双主题对齐清单与截图 QA 流程）。

## 升级说明

- 配置新增 `hideTaskbar`（默认 `true`）、`theme`（默认 `"system"`）、`syncSystemTheme`（默认 `true`）；
  旧配置可直接升级，缺省字段按默认值处理。
- 若启动后不希望隐藏任务栏：顶栏齿轮 → 管理面板 → 通用 → 关闭「隐藏系统任务栏」。
- 若 easy-dash 被强制结束导致任务栏未恢复：重新启动 easy-dash，或重启 `explorer.exe`。
- 开发/排障环境变量：`EASYDASH_DISABLE_TASKBAR_HIDE=1`（完全跳过隐藏）、
  `EASYDASH_TASKBAR_BRIDGE_VISIBLE=1`（桥接期间真正显示任务栏）、`EASY_DASH_NO_ADMIN=1`（无管理员清单构建测试）。

## 已知限制

- 隐藏任务栏不释放其 AppBar 保留的工作区条带；托盘桥接为 best-effort，降级时管理面板显示桥接状态。
- 强制结束 easy-dash 后任务栏可能保持隐藏，按上文恢复。
- 应用中心搜索状态下禁用拖拽排序；跨页拖拽需在网格上下边缘停留约 0.55s 触发翻页。
- 隐藏任务栏期间，无 tooltip 的托盘图标无法通过屏幕截图做视觉匹配，可能回退通用占位。
- 主题跟随依赖读取 `HKCU\...\Themes\Personalize\AppsUseLightTheme`，读取失败时回退深色。

## 系统要求

- Windows 10 / Windows 11 x64（推荐 Windows 11；托盘镜像 / 通知中心 / 控制中心依赖 Win11 XAML 任务栏与 UIA）。
- WebView2 Runtime：Windows 11 自带；Windows 10 缺失时安装器/系统会提示安装。
