# easy-dash v0.2.1

实机反馈问题修复版本：主题收敛为浅色 / 深色两态，任务栏隐藏后窗口可占满全屏，托盘镜像点击真正生效，
并加入中国农历、通知堆叠增强与控制中心磁贴交互重构。

## 修复

- **任务栏隐藏后窗口无法占满全屏**：只接管主显示器工作区（`SPI_GET/SETWORKAREA`）并不稳定——
  顶栏托盘镜像每 10s 刷新、每次托盘点击都会把 `SW_HIDE` 的任务栏 `SW_SHOW` 一次，Explorer 随即
  按仍注册的任务栏 AppBar 把底部条带重算回工作区（`(0,32)-(1920,1080)` → `(0,32)-(1920,1032)`），
  最大化窗口被永久压回 1032–1034 且不会自行长回。现改为「隐身模式」隐藏任务栏：窗口保持 visible，
  但置 `WS_EX_LAYERED` + alpha 0 + `WS_EX_TRANSPARENT`（鼠标穿透），不再有任何显示/隐藏跳变，
  Explorer 不再重算工作区，工作区接管因此稳定；托盘点击前后仅临时关闭穿透（约 100ms），
  UIA 枚举不做可见性/穿透切换（底部不留点击死区）。`SW_HIDE` 仅作为隐身不可用（如 UIPI 拒绝改样式）
  时的兜底；恢复时同时清除 `WS_EX_LAYERED` / `WS_EX_TRANSPARENT` 并自愈崩溃残留，避免任务栏
  「可见但点不动」。退出、关闭开关或重载配置时恢复原始工作区；watchdog 检测到 Shell 重置后自动纠正。
  真机实测：工作区稳定在 `(0,32)-(1920,1080)`（25s / 100ms 采样零跳变），最大化窗口 `visibleFrame`
  底部为 1080（铺满屏幕）；已存在的最大化窗口可能仍需先还原再最大化一次才会使用新工作区。
- **顶栏托盘镜像点击无功能**：点击时把任务栏以 `alpha=0` 保持显示，直到托盘弹窗关闭后再隐藏
  （此前点击后立即隐藏会把 Owner 为任务栏的弹窗一起关掉）；无弹窗时用可见任务栏兜底重试。
  诊断日志：`%APPDATA%\com.easydash.app\tray-click.log`（超过 64KB 自动截断）。
- **浅色主题托盘图标出现深色底**：`tray-dark` 的浅色垫底只在深色主题生效。
- **Dock 启动瞬间位置/尺寸不对**：Dock 窗口改为「首帧校正完成后再显示」（此前先以 900px 占位宽 + 旧工作区底部出现，
  要等内容变化触发 `syncSize` 才恢复）；`resize_dock` 的底部基准由屏幕底边改为**当前工作区底边**，
  任务栏显隐/重载配置后后端主动重新贴边（任务栏可见时 Dock 不再被压住）。
- **顶栏托盘图标「在但点不动」**：`tray_click` 增加 `order_key` 兜底（托盘项增减会导致后端缓存索引漂移，
  此前会静默失败）；取不到项时写入 `tray-click.log` 并在图标旁短暂提示，便于定位。
- **新增「退出程序」入口**：管理面板 → 通用 →「退出 easy-dash」（3 秒二次确认），
  控制中心电源菜单也新增「退出 easy-dash」；走正常退出流程（恢复任务栏与工作区），
  用于托盘右键菜单异常时兜底退出。
- **白色 Dock 的九点格图标不可见**：图标改用 `currentColor`，浅色主题下自动变深色。
- **控制中心磁贴图标可能溢出容器**：图标泡裁剪 + SVG 尺寸上限，hover/缩放不再越界。
- **通知中心消息堆叠不明显**：堆叠层加大露出与边框对比，增加条数徽标，展开后隐藏。
- 管理面板「当前外观」状态与「同时控制系统主题」说明更新为两态语义。

## 变更

- **移除「跟随系统」主题**：只保留浅色 / 深色，避免与 Windows 系统主题互相干扰；默认 `dark`，
  旧配置 `theme="system"` 自动迁移为 `dark`；后端不再轮询系统主题。
- **控制中心重构**：移除主视图「连接」模块；Wi-Fi / 蓝牙磁贴改为「点图标开关、点其余区域进入连接列表」，
  飞行模式整块切换；控制中心窗口高度收紧，卡片间距恢复 8px，无内部滚动条。
- **日历集成中国农历**：日期格显示农历日/月（节日优先），标题提示完整农历与干支；
  头部显示干支生肖；换算使用本地 1901–2100 年表（.NET `ChineseLunisolarCalendar` 生成，离线无依赖）。

## 升级说明

- 配置文件新增/变更：`theme` 只接受 `light` / `dark`（默认 `dark`）；`hideTaskbar`、`syncSystemTheme` 语义不变。
- 若启动后不希望隐藏任务栏：顶栏齿轮 → 管理面板 → 通用 → 关闭「隐藏系统任务栏」。
- 若 easy-dash 被强制结束导致任务栏未恢复：重新启动 easy-dash，或重启 `explorer.exe`。

## 已知限制

- **多显示器工作区**：Windows 只为主显示器提供 `SPI_SETWORKAREA`，次要显示器仍保留任务栏占用的条带。
- 托盘桥接为 best-effort：系统限制跨进程窗口样式或 UIA 暂时不可用时，托盘镜像会降级（管理面板显示状态）。
- 通知中心是系统通知历史的只读镜像；节假日数据覆盖 2024–2026，农历覆盖 1901–2100。
- 主题仅两态；「同时控制系统主题」只影响之后在控制中心的切换，不会立即改系统。
