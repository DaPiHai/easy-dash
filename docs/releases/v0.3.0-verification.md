## 未能自动验证（需要人工点一次）

以下项目受环境限制：easy-dash 以管理员权限运行，DSH 的 CUA/鼠标注入处于 Medium integrity，UIPI 会静默丢弃对 High integrity 窗口的点击，因此无法程序化点击顶栏/面板/托盘：

1. 副屏控制中心里把「副屏顶栏」关掉 → 副屏顶栏与顶部预留立即消失；再开恢复。
2. 副屏控制中心「副屏 Dock」关掉 → 副屏 Dock 隐藏。
3. 副屏托盘图标右键 → 菜单出现在副屏顶栏图标下方；`%APPDATA%\com.easydash.app\tray-click.log` 新增 `monitor=\\.\DISPLAY1` 且 `at` 坐标在副屏范围。
4. 副屏齿轮 → 管理面板在副屏工作区居中；Esc/关闭正常。
5. 拔掉/重新接上副屏（或改分辨率/缩放）→ 约 2 秒内窗口重建，无重影；主屏保持正常。
6. 关闭「隐藏系统任务栏」后副屏顶部/左侧任务栏时顶栏避让。

> 上述 1/2 的代码路径由 `surfaces::apply_config`（显隐 + AppBar 注册/注销）与无头卡片交互覆盖；3/4 的坐标换算由 `ClientToScreen` + `GetDpiForWindow` 与按屏 bounds 实现，仍需真机点击确认。

## 备注

- 副屏底部空白已通过临时开启任务栏 `ABS_AUTOHIDE` 修复：不修改任务栏 AppBar 注册，Explorer 重算所有屏工作区；原状态写入 marker，退出/下次启动恢复。关闭「隐藏任务栏」时条带随任务栏恢复。
- 独立探针（任务栏隐身 + `ABM_SETSTATE`）验证：副屏 work bottom 3383 → 3455，主屏 2488 → 2560；恢复后分别回到 3383 / 2488。
- 初始启动是 100%/150% 混合 DPI；窗口几何全部使用物理像素 + 各屏 `scale_factor`。
- 首轮发现并修复：隐藏窗口 `set_size/set_position` 经 tao `SWP_ASYNCWINDOWPOS` 会与 `show()` 抢时序，导致概览/应用中心停在初始 1280×720；已改为同步 `SetWindowPos`（`winapi::common::set_window_rect`），并在 show 后再校正一次。
