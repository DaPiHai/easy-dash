# easy-dash v0.1.0

首个公开版本：一个轻量的 Windows 桌面增强工具，界面风格参考 GNOME。提供顶栏、通知中心、控制中心、任务托盘镜像、Dock、应用中心、活动概览与管理面板。

## 亮点

- **顶栏**：活动按钮、时钟日期、任务托盘镜像、网络/音量/电池状态；AppBar 预留空间，全屏应用时自动隐藏。
- **通知中心**：左右两栏布局，通知按应用分组堆叠并显示真实图标；右侧接入中国法定节假日日历与媒体播放控件。
- **控制中心**：Wi-Fi 连接、蓝牙设备连接、音量/亮度、深色模式、电源模式与电源动作。
- **任务托盘镜像**：Windows 11 托盘图标同步到顶栏，支持拖拽排序；应用菜单/浮层锚定顶栏图标下方。
- **Dock 与应用中心**：Gnome 风格 Dock + 全屏应用网格，支持搜索、方向键导航、拖拽排序、导入自定义应用。
- **管理面板**：顶栏齿轮打开，集中管理开关、热键、固定应用、导入应用与托盘顺序。
- **活动概览 / 热键**：`Alt+F1` 概览，`Alt+Space` 应用中心。

## 安装

1. 下载本 Release 附件 `easy-dash_0.1.0_x64-setup.exe`。
2. 双击运行，按向导完成安装（默认当前用户，无需管理员权限）。
3. 从开始菜单启动 easy-dash；启动后顶栏与 Dock 出现。
4. 卸载：Windows「设置 → 应用 → easy-dash」。

## 系统要求

- Windows 10 / Windows 11 x64（推荐 Windows 11）。
- WebView2 Runtime：Windows 11 自带；Windows 10 缺失时安装器/系统会提示安装。
- 托盘镜像、通知中心、控制中心依赖 Windows 11 的 XAML 任务栏与 UI Automation；Windows 10 下这些能力自动降级隐藏。

## 配置

- 配置文件：`%APPDATA%\com.easydash.app\config.json`
- 管理面板可修改的配置会立即写盘；手动编辑后可用系统托盘菜单「重载配置」生效。
- 配置中的托盘/应用排序、导入应用、Dock 固定项均会持久化。

## 已知限制

- 通知中心是 Windows 通知历史的只读镜像：不能在 easy-dash 内删除系统通知，不含勿扰开关。
- 任务托盘图标来自系统快照：动态角标/红点不同步；纯黑图标会自动加浅色底。
- 托盘弹窗锚定为 best-effort：部分 Electron/Qt/UWP 浮层或受 UIPI 限制的应用会保持系统原生位置。
- 拖拽排序只改变 easy-dash 内显示顺序，不修改 Windows 原生托盘/开始菜单顺序。
- 管理面板「添加固定应用」仅支持 `.exe/.lnk/.url`（UWP/文件夹固定请用 Dock 右键）。
