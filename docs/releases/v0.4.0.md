# easy-dash v0.4.0

视觉与手感版本：液态玻璃 2.0、iOS 动效层、鼠标流光，加上一批影响日常使用的缺陷修复
（Dock 缩成小方块、顶栏盖住桌面图标、微信托盘左键点不动、顶栏玻璃变成一条纯色）。

## 新增

- **液态玻璃 2.0（macOS 控制中心式光学分层）**
  - 真实桌面取样：面板展开前 Rust 截取面板将占据的屏幕矩形（`ClientToScreen` + `GetDpiForWindow` 处理多屏 / DPI），
    缩到宽 ≤480、JPEG q72，返回 `{ dataUrl, p05, p95, mean }`；WebView2 透明窗口的 `backdrop-filter` 采不到桌面，
    这是玻璃能真实透出壁纸的可靠路径。
  - 四层光学结构：玻璃体（取样图 + 自适应色阶 + 白偏光）→ 镜面层（噪点 + 顶部镜面线 + 多重 inset 边缘）→
    折射层（`feDisplacementMap`）→ 同色系三段投影（颜色由背景平均色推出，不纯黑）。
  - 自适应对比度（`ui/js/glass-math.js`）：按取样亮度分位在 sRGB 空间解最小色阶 alpha，正文目标 4.7:1；
    暗色再叠「背景越亮、玻璃越实」的材质密度；`npm run check:glass` 断言矩阵守护（正文 ≥4.5、蓝玻璃白字 ≥3.5、
    亮色色阶 ≤.62、阴影无纯黑）。
  - 蓝玻璃控件：开启态磁贴 / 开关改为半透明蓝，按背景在 `.6–.9` 自适应，配顶部白高光与蓝调外阴影。
  - 全部表面同步：顶栏 18px、Dock 24px、管理面板 / 概览 / 应用中心 30px 模糊；顶栏 / Dock 底片常驻不再重截。
  - 降级：非 liquid、截屏失败、近黑 / 受保护内容、超时都回落 `[data-glass="fallback"]`，面板照常打开。
- **界面材质**：新增独立材质维度 `material`（`solid` / `liquid` / `glow`），与明暗主题正交；控制中心「外观」卡
  与管理面板「外观」页互通，即时生效并持久化。弹层在玻璃材质下使用真实 `backdrop-filter`。
- **iOS 手感动效层**：统一按压缩放（`scale .96` + 弹性回弹）、分段控件滑动滑块、面板抽屉进出场、通知分组错峰入场、
  开关滑块弹性横移、Dock 启动图标弹跳；新增动效 token，一次性动画最长 820ms，`prefers-reduced-motion` 下整体让位。
- **鼠标流光**：光标掠过顶栏 / Dock / 面板 / 磁贴 / 卡片时跟随柔光（60–110ms 甩尾）；液态玻璃下描边有沿边缘绕行的
  光带（4.2s/圈，指针方位决定起始角）；按下时从落点扩散点按光晕。单 `pointermove` + rAF 合并，rect 缓存避免逐帧强制
  布局；管理面板「外观 → 鼠标流光」开关（`config.pointerGlow`）。
- **Dock 智能自动隐藏**：普通窗口压到 Dock 区域时约 260ms 滑下隐藏（窗口矩形每 240ms 扫描），移开 / 还原后恢复常驻；
  鼠标移到 Dock 底边临时滑出，离开约 450ms 再隐藏；隐藏期间 Dock 对鼠标透明。配置 `dockAutoHide`。
- **桌面图标避让**：新增 `winapi/desktop.rs`，把 Explorer 桌面图标视图（`SysListView32`）整体下移顶栏高度，
  启动 / 多屏重排 / 配置热更新后应用，monitor 线程每 2s 补回，退出时移回整屏；目标矩形由虚拟屏矩形推导 → 幂等，
  强杀残留不会叠加偏移。
- **活动概览 / 应用中心打开动画**：遮罩淡入 200ms + 内容上浮 300–320ms 弹性 + 卡片 24ms / 图标 10ms 错峰；
  新增 `ui/js/surface-open.js` 统一控制，等玻璃底片补截完成后再播动画，避免在「隐藏截屏」阶段被吃掉。
- 新增调试环境变量 `EASYDASH_GLASS_DEBUG=1`（玻璃底片取样结果写日志）与 `EASYDASH_WEBVIEW2_ARGS`
  （给 WebView2 追加参数，例如 `--remote-debugging-port=9333`）。

## 修复

- **微信截屏（Alt+A）/ 全屏后 Dock 缩成屏幕底部一个小方块**：全屏状态类改为 `fs-hidden`，不再与全局
  `.hidden { display:none }` 撞名；`syncSize()` 增加布局守卫（`getClientRects()` 为空或 <60×40 直接跳过），
  退出全屏 / 页面恢复时强制重算；Rust 侧 `resize_dock_window()` 兜底丢弃不合理尺寸。
- **顶栏盖住桌面图标**（回收站缺了盖子）：根因是 Explorer 桌面图标视图铺满整块屏幕、不理会工作区，
  改用整体下移视图矩形的方式避让。
- **顶栏托盘左键点不动 v4 应用（微信等）**：`version` 改为从 `NIM_ADD/MODIFY` 的 `uVersion` 读取，
  按真实 Explorer 协议发送（v4 左键只发 `NIN_SELECT`、右键只发 `WM_CONTEXTMENU`）；Qt 窗口类兜底按 v4 发送。
  另加「激活后窗口完全不在任何显示器上」的越界兜底。
- **顶栏 / Dock 玻璃「变成一整条纯色」**：底片改为直接采样壁纸（`SPI_GETDESKWALLPAPER` + 铺法还原），
  不再把启动瞬间的前台窗口标题栏烘进玻璃；移除前端 `glass_backdrop` 对顶栏 / Dock 的覆盖。
- **应用中心不响应主题变更**：补 `import "./theme.js"`。
- **打开全屏表面时闪一下上一次的界面**：Rust `hide()` 后派发 `surface-closed`，页面立即回到关闭态（无过渡），
  下次 `show()` 第一帧就是透明的。
- 面板关闭改为「先动画、后缩窗口」（150ms），其他面板互切仍即时隐藏。

## 变更

- 控制中心窗口高度 644 → 688、面板 560 → 604（外观卡新增材质分段，保持无滚动条）。
- 管理面板「当前外观」状态行改为「深色 · 液态玻璃 · Windows 浅色」三段式。
- 浅色去白底：所有表面的亮色白色阶上限 `.14`（常规 `.10`），并按合成亮度自适应黑 / 白墨色
  （`data-ink="light"`），不再铺大面积白底。
- 文档：新增 `docs/design-system.md` 的材质 / 动效 / 鼠标流光章节与截图矩阵；`README.md` 重构为
  面向新读者的介绍 + 截图 + 文档索引，配置与限制分别移到 `docs/config.md`、`docs/limits.md`。

## 升级说明

- 配置新增 `material`（默认 `solid`）、`pointerGlow`（默认 `true`）、`dockAutoHide`（默认 `true`）；
  旧配置自动补齐。`theme` 的 `system` 会迁移为 `dark`。
