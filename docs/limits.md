# 已知限制（v0.4）

按能力分组。标 **降级** 的条目表示不满足条件时会自动隐藏入口或回落到简化实现，而不是报错。

## 多显示器与工作区

- **多显示器**：顶栏默认每屏显示、Dock 默认仅主屏，可在控制中心「多屏」卡片切换；活动概览 / 应用中心只在触发屏
  打开（不跨屏铺满）；窗口缩略图为打开概览时的静态截图（非实时），最小化窗口回退到最后一次可见时缓存的画面。
- **隐藏系统任务栏**：隐藏后接管主显示器工作区（`SPI_SETWORKAREA`），并临时把系统任务栏设为 `ABS_AUTOHIDE`，
  使 Explorer 重算**所有显示器**工作区、释放副屏底部条带；副屏顶部仍由每屏顶栏 AppBar 预留。**不修改任务栏的
  AppBar 注册**，退出 / 下次启动把 auto-hide 恢复原值（原状态写入强杀标记，异常退出也能恢复）。若在管理面板关闭
  「隐藏任务栏」，副屏底部条带会随任务栏恢复。
- **桌面图标避让**：Explorer 的桌面图标视图是**一整块虚拟屏**、不按屏分别布局，因此避让是整体下移顶栏高度；
  若关闭了「副屏顶栏」（`topbarAllMonitors=false`），那块副屏的图标也会下移同样的高度、顶部留一条 32px 空白。
  视图矩形由 easy-dash 在启动 / 多屏重排 / 配置热更新时设置，monitor 线程每 2s 补回（Explorer 重启、F5 刷新桌面、
  改分辨率会重置），退出时移回整屏；被强杀后残留的下移会随下次启动（或重启 `explorer.exe`）恢复。
- **管理面板「预留顶栏空间」**：即时注册 / 注销 AppBar 并影响工作区高度；若系统 AppBar / 工作区状态异常，
  重启 easy-dash 可恢复。

## Dock

- **Dock 智能隐藏**只由「普通应用窗口矩形与 Dock 区域相交」触发；桌面、最小化窗口、其他虚拟桌面（DWM cloaked）、
  工具窗口与 easy-dash 自身窗口不计入。全屏隐藏优先，全屏期间底边不唤出；可在管理面板「通用」关闭。
  隐藏时 Dock 窗口对鼠标透明，点击落到下方应用。
- Dock 中的未固定应用按**窗口打开顺序**排列（不随聚焦变化）；UWP 应用失焦挂起后（DWM cloaked=2）仍保留在 Dock 中，
  其他虚拟桌面的窗口也会显示。
- UWP 应用（如「设置」）固定到 Dock 时记录 AppsFolder 启动器，图标取自包清单。

## 顶栏与托盘代理

- **托盘代理窗口**：easy-dash 在自身进程注册类名 `Shell_TrayWnd` 的置顶窗口，应用通过 `FindWindow` 找到它；
  代理把 `WM_COPYDATA` 原样转发给真实托盘。若同时运行其它同类代理 / Shell 替换工具，可能互相抢占图标；
  点击 / 图标诊断写入 `%APPDATA%\com.easydash.app\tray-click.log`（超过 64KB 自动截断），设置
  `EASYDASH_TRAY_DEBUG=1` 可记录 NIM 原始字段。
- **托盘点击协议**：按 `NOTIFYICON_VERSION_4` 区分——v4 应用（微信、Qt 系）左键只发 `NIN_SELECT`、右键只发
  `WM_CONTEXTMENU`（真实 Explorer 也是这么做的；Qt 完全忽略 `WM_LBUTTONUP`）；v0–v3 才发按下 / 抬起。
  版本号取自 `NIM_ADD/MODIFY/SETVERSION` 的 `uVersion`，并识别 Qt 窗口类兜底（`uVersion` 读不到时也按 v4 发送）。
  左键激活后若前台窗口完全不在任何显示器上（显示器拔掉后仍记得旧坐标），代理会把它夹回顶栏所在屏的工作区。
- **图标来源**：托盘图标来自代理收到的 `HICON`，**不依赖任务栏截图**；动态角标 / 红点 / 登录状态会随 `NIM_MODIFY`
  更新。无 tooltip 时回退 exe 主名；深色 / 浅色主题下会做图标可见性修正。
- **系统图标去重**：托盘代理显示第三方应用已注册图标（包括原生折叠区），但会过滤 `explorer.exe` 持有的 Shell
  系统图标（电量、音量、蓝牙设备、安全删除硬件等），避免与右侧状态区重复；顶栏不提供「» 展开 / 折叠」。
- **UIA 回退模式只在主屏顶栏显示托盘**：托盘代理启动失败时才走 UIA 镜像，此时副屏顶栏不显示托盘图标
  （避免把副屏点击映射到主屏任务栏）；代理模式（正常路径）每块屏都显示。
- **右键菜单**：Qt / 微信等在 v0 回调下会先把菜单开在主窗口左下角；抖音的 `LynxContextMenu` 在点击前是隐藏窗口、
  点击后变为可见。代理会记录点击前**可见**窗口，在点击后 1.5s 内识别新出现 / 由隐转显的菜单，并把越界或盖住顶栏的
  菜单夹回顶栏图标下方。仍有个别应用完全忽略回调坐标、或菜单尺寸超过屏幕，可能表现异常。
- **异常退出**：easy-dash 被强制结束（任务管理器 / 崩溃）时任务栏可能保持隐藏；同时代理窗口消失后，应用图标会暂时
  从原生托盘消失（应用以为仍注册在代理上）。重新启动 easy-dash（启动即广播 `TaskbarCreated`，应用会重新注册并恢复
  原生托盘）或重启 `explorer.exe` 即可恢复；正常退出会先广播再恢复任务栏。
- 顶栏音量图标支持**滚轮调节**（5%/格，顶栏内 OSD 提示）；控制中心音量 / 亮度滑条也支持滚轮，拖拽行为不变。
  顶栏滚轮依赖 Windows「悬停非活动窗口时滚动」设置（默认开启）；关闭时需先点击顶栏再滚轮。
- 音量图标为状态显示 + 滚轮调节；静音与精确调节仍使用控制中心。

## 通知中心 / 控制中心

- **依赖 Windows 11（XAML 任务栏 + UI Automation）**；不支持时对应入口自动隐藏。任务托盘代理本身不依赖 XAML
  （Win10/11 均可），但本项目主要在 Windows 11 26H2 验证。
- **通知中心是 Windows 通知历史的只读镜像**：不能在 easy-dash 内删除系统通知（「清除全部」仅本地隐藏），
  也不含勿扰开关；通知图标来自托盘图标快照 / exe 图标，个别未登记应用回退字母占位。
- **通知中心「打开应用」**依赖通知处理器 → AppsFolder / 开始菜单的映射：无法映射的处理器（多为 `app:system`
  系统通知）不显示入口；目标应用已运行时是否切到前台取决于应用自身的单实例行为，easy-dash 不强制激活已有窗口。
- **通知中心系统入口**：Windows 自己的通知中心仍由系统决定弹出屏幕（通常主屏）；亮度滑条仍控制第一台支持
  DDC/CI 的显示器，暂不按触发屏选择。
- 节假日数据固化在 `ui/js/cn-holidays.js`（2024–2026，来源 timor.tech，2026-10-25 抓取）；2027 及以后年份
  需补充数据后才显示标记。
- 农历由 `ui/js/lunar.js` + `ui/js/lunar-table.js` 本地换算（1901–2100，数据由 .NET `ChineseLunisolarCalendar` 生成）；
  超出范围或非公历日期不显示农历。
- 媒体控件依赖 Windows SMTC：未注册 SMTC 的播放器不显示；无封面时使用占位。
- Wi-Fi 连接支持开放 / WPA / WPA2 / WPA3 个人网络；**企业级 802.1X 与隐藏网络需在系统设置中连接**；
  蓝牙「连接」通过启停设备音频服务实现（best-effort），**配对新设备仍走 Windows 设置**。
- 蓝牙开关首次切换时系统可能弹出一次授权提示；Windows 自身把任务栏设为自动隐藏时不影响托盘代理
  （任务栏显隐由 easy-dash 管理）。
- 亮度滑条依赖显示器 DDC/CI；外接屏或部分机型不支持时自动隐藏。

## 主题 / 材质 / 玻璃

- **主题**：仅浅色 / 深色两态；首帧用 `localStorage` 缓存避免闪烁；「同时控制系统主题」只影响之后在控制中心的切换，
  不会立即改系统；老配置的 `theme: "system"` 会迁移为 `dark`。
- **顶栏 / Dock 的液态玻璃底片取自壁纸**（`SPI_GETDESKWALLPAPER` + `WallpaperStyle` / `TileWallpaper`，支持
  fill/span/stretch/fit/center/tile），因此不会跟随下方窗口颜色变化，也不再用截屏补拍（截屏会被启动瞬间的前台窗口
  标题栏污染）；纯色桌面、取不到壁纸或解码失败时回退为截屏取样。控制中心 / 通知中心等「盖在窗口上」的面板仍按
  打开时的桌面截屏取样。
- 浅色主题不再对图标整体做 `brightness` 压暗（白底图标会变成半透明黑块），改为给透明边缘加细 `drop-shadow`；
  深色主题仍只对近黑透明图标垫浅色底。

## 应用中心

- **分页网格**：滚轮 / 触控板 / PageUp·PageDown 换页，不再纵向滚动；搜索状态下禁用拖拽排序；
  跨页拖拽需把卡片拖到网格上下边缘停留约 0.55s 触发自动翻页。
- 列表 = Start Menu（用户 + 公共）快捷方式 + WinRT 打包应用；启动时后台枚举，超过 5 分钟或手动刷新时重扫；
  **控制面板项、分类 / 最近使用 / 拼音搜索暂不支持**（仅名称子串过滤）。
- 打包应用枚举失败（权限 / 系统异常）时**降级为仅经典应用**并在日志记录；个别应用无 `AppListEntry` 时不展示；
  图标统一 48px，提取失败回退字母占位。
- **导入应用**只记录路径并加入应用中心，不复制文件、不写入 Windows 开始菜单；仅支持 `.exe/.lnk/.url`，
  不支持参数编辑（`args` 字段预留）；右键「移除导入应用」只从 easy-dash 移除，不卸载程序。
- **拖拽排序只改变 easy-dash 内的显示顺序**，不会修改 Windows 原生托盘 / 开始菜单顺序；托盘排序按稳定 key
  （exe 主名 / 注册表匹配 + 同源 `#序号`）持久化，应用中心按应用 id 持久化，新增应用 / 图标会追加到已排序项之后。

## 管理面板

- 管理面板中「添加固定应用」仅支持 `.exe/.lnk/.url` 文件（UWP / 文件夹固定仍走 Dock 右键）；
  热键冲突时保存后界面会显示警告，旧热键已被注销，可在面板里换一个组合。
- `Alt+Space` 被 easy-dash 全局占用，**会覆盖系统「窗口菜单」快捷键**；若被其它程序占用导致注册失败，
  仅日志提示（Dock 入口仍可用，可在 `config.json` 改 `appCenterHotkey` 后重载配置）。

## 权限

- 部分系统级能力（亮度、电源动作等）可能触发 Windows 权限提示。
- exe 内嵌 `requireAdministrator` 清单：**每次启动会弹 UAC**（详见 [README → 管理员权限说明](../README.md#管理员权限说明)）。
