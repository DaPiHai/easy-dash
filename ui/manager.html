通用

全屏自动隐藏
全屏应用运行时自动隐藏顶栏与 Dock
Dock 智能隐藏
普通窗口压到 Dock 区域时自动滑下隐藏；鼠标移到 Dock 底边可临时唤出，移开后再次隐藏
预留顶栏空间
把顶栏注册为 AppBar，最大化窗口自动避开
顶栏托盘镜像
在顶栏右侧显示系统托盘图标（Windows 11）
通知中心
点击顶栏时钟打开通知 / 日历 / 媒体
控制中心
顶栏右侧的 Wi-Fi / 音量 / 电池入口
隐藏系统任务栏
运行时隐藏 Windows 任务栏，退出时自动恢复；顶栏托盘图标通过桥接保留

退出

退出 easy-dash
退出程序并恢复系统任务栏与工作区；托盘右键菜单异常时的备用入口

外观

同时控制系统主题
在控制中心切换亮/暗主题时同步修改 Windows 系统主题；关闭后 easy-dash 与系统主题各自独立
界面材质
液态玻璃：通透高光 + 镜面边；柔光玻璃：柔和弥散 + 低对比；标准为原有观感
鼠标流光
光标掠过顶栏、面板与卡片时跟随的柔光高光；液态玻璃下额外有边框流光
当前外观
明暗在控制中心「外观」中切换；材质可在上方或控制中心切换（均即时生效）
